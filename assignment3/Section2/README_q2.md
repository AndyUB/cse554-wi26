# Section 2 Q2: Attention Benchmark Commands

## 1) Install FlashInfer
```bash
uv pip install flashinfer-python==0.5.3
```

## 2) Run all benchmarks (torch SDPA vs FlashInfer)
This writes CSVs under `assignment3/Section2/results/`.

```bash
python assignment3/Section2/benchmark_attention.py --warmup 20 --iters 100
```

Optional quick sanity run:
```bash
python assignment3/Section2/benchmark_attention.py --warmup 5 --iters 10
```

## 3) Generate plots
This reads CSVs and writes figures to `assignment3/Section2/figures/`.

```bash
python assignment3/Section2/plot_attention_p.py
```

Generated figures:
- `prefill_vs_p.png`
- `prefill_vs_batch.png`
- `decode_vs_c.png`
- `decode_vs_batch.png`
- `decode_vs_page_size.png`

## Notes
- Benchmarks require a CUDA GPU.
- The script benchmarks one attention layer using fp16.
- `plot_attention_p.py` expects benchmark CSVs generated by `benchmark_attention.py`.
